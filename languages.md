# Language coverage

The selector offers **19 languages: 10 world languages and 9 Turkic languages**. Only choices with actual translated interface messages are included. The previous English-only placeholder entries have been removed; this is not a claim to cover every Turkic language or dialect.

Changing language translates the interface only. It does not translate, upload or alter file names, file contents, CSV cells or pasted text.

## Translation status

- **Partial:** Azerbaijani (`az`), Kazakh (`kk`), Uzbek (`uz`), Kyrgyz (`ky`) and Turkmen (`tk`) have 270+ translated messages covering the main navigation, common controls, home screen, new tool labels and all 30 contextual tutorial instructions. Tatar (`tt`), Bashkir (`ba`) and Uyghur (`ug`) have a smaller translated core. Other explanations, uncommon runtime messages and future feature descriptions can fall back to English.
- **Missing messages:** A partially translated language uses English only for individual messages that are not yet translated. English-only placeholder languages are not listed in the selector.
- All supplied translations are drafts. They have not been reviewed by professional translators or native-language maintainers. Contributions and corrections are welcome.
